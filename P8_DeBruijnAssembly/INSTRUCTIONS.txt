P8: DE BRUIJN GRAPH ASSEMBLY
Quick Start Instructions

================================================================================
SIMPLEST WAY TO RUN (1 command):
================================================================================

cd P8_DeBruijnAssembly
python3 simple_test.py

This will:
- Test assembly with different genome lengths
- Test assembly with different coverage levels
- Test assembly with different error rates
- Generate a summary report

Results will be in: simple_test_results/SUMMARY_REPORT.txt

================================================================================
RUN A SINGLE ASSEMBLY EXAMPLE:
================================================================================

python3 run_assembly.py --length 1000 --coverage 10 --read_length 100 --kmer 21

This will:
1. Generate a 1000bp random DNA sequence
2. Simulate sequencing at 10x coverage with 100bp reads
3. Extract 21-mers from the reads
4. Assemble using a De Bruijn graph
5. Calculate statistics and compare to Lander-Waterman prediction

Results will be in: assembly_output/

================================================================================
RUN INDIVIDUAL STEPS:
================================================================================

# Step 1: Generate DNA
python3 dna_generator.py --length 1000 --output genome.fasta

# Step 2: Simulate sequencing
python3 sequencing_simulator.py --input genome.fasta --coverage 10 --read_length 100 --output reads.txt

# Step 3: Extract k-mers
python3 kmer_generator.py --input reads.txt --k 21 --output kmers.txt

# Step 4: Assemble contigs
python3 debruijn_assembler.py --input kmers.txt --output contigs.fasta

================================================================================
WHAT THE TESTS SHOW:
================================================================================

The test results demonstrate:

1. At 10x coverage, genomes assemble into 1 contig (perfect!)
2. At 5x coverage, there are gaps (incomplete assembly)
3. At 20x coverage, assembly is excellent

4. With 0% errors, assembly is perfect
5. With 0.1% errors, assembly breaks into ~50 contigs
6. With 1% errors, assembly breaks into ~285 contigs

Conclusion: Sequencing errors dramatically affect assembly quality!
The Lander-Waterman equation only works for error-free sequencing.
